# ✈️ Airline Analytics  
**Data-Driven Insights into Airline Pricing & Performance**

## 📌 Project Overview
**Airline Analytics** is an end-to-end data analytics project focused on exploring, analyzing, and visualizing airline flight pricing data in Bangladesh.  
The goal of this project is to transform raw flight data into **actionable business insights** that support better decision-making for airlines, travelers, and analysts.

This project demonstrates strong skills in **data analysis, business intelligence, and storytelling through dashboards**.

---

## 🎯 Objectives
- Analyze airline ticket pricing patterns across routes and airlines  
- Identify key factors influencing flight prices  
- Build an interactive Power BI dashboard for business insights  
- Present insights in a clear, decision-oriented manner  

---

## 📊 Dataset
- **Source:** Flight Price Dataset of Bangladesh  
- **Format:** CSV  
- **Key Attributes:**
  - Airline name  
  - Source & destination  
  - Flight duration  
  - Stops  
  - Departure & arrival time  
  - Ticket price  

📁 File: `Flight_Price_Dataset_of_Bangladesh.csv`

---

## 🛠️ Tools & Technologies
- **Power BI** – Data modeling, DAX, and interactive dashboards  
- **Microsoft Excel / CSV** – Raw data handling  
- **Data Analytics Concepts** – EDA, KPI analysis, trend identification  

---

## 📈 Dashboard Highlights
- Airline-wise price comparison  
- Route-based fare analysis  
- Impact of stops and duration on pricing  
- Trend analysis for flight costs  
- User-friendly slicers for dynamic filtering  

📂 Power BI File: `Airline Analytics.pbix`

## 💡 Key Insights
- Flight prices vary significantly by airline and route  
- Non-stop flights generally cost more but save travel time  
- Duration and departure timing have a noticeable impact on pricing  
- Certain routes show consistent price patterns suitable for forecasting
